# Codes for BTSP and STDP learning 

This repository contains the code for the BTSP and STDP (Hebbian) learning.

## Version Requirements
- **Python**: `3.10`

## Descriptions
The compressed files `car1_1.zip`, `car1_2.zip`, and `car2.zip` are the dataset.
`btsp_**` and `stdp_**` used to implement two learning rules. `associate_memory.py` used to test associate_memory. `cluster.py` used to test t-SNE analyse.

## Examples
Runing `btsp_learning.py` first and then `btsp_recall.py` can obtain the memory representations of learned images. The firing probability of plateau potentials can be modulated by“FOLDER-COLUMN”
